✅
이미 홈 화면에 추가되어 있어요!
앱 아이콘을 탭해서 바로 실행하세요.
🤖
안드로이드 (Chrome) 설치 방법
1
아래 홈 화면에 추가 버튼을 탭하세요.
2
팝업이 뜨면 설치 또는 추가 를 탭하세요.
3
홈 화면에 동네로 아이콘이 생기면 완료!
💡 버튼이 활성화되지 않는 경우
Chrome 주소창 우측 ⋮ 메뉴 → '홈 화면에 추가' 또는 '앱 설치'를 선택해 주세요.
🍎
아이폰 (Safari) 설치 방법
1
화면 하단의 □↑ 공유 버튼을 탭하세요.
메뉴바가 숨겨진 경우 화면을 한 번 탭하면 나타나요
2
아래로 스크롤해서 홈 화면에 추가 를 탭하세요.
3
우측 상단 추가 를 탭하면 완료!
💡 Safari에서 접속해야 홈 화면 추가가 가능해요.
다른 브라우저(Chrome 등)에서 접속 중이라면 Safari로 열어주세요.
💻
설치 방법
1
Chrome 주소창 우측 ⋮ 메뉴 를 클릭하세요.
2
홈 화면에 추가 또는 앱 설치 를 선택하세요.
💡 버튼이 비활성화 상태라면 Chrome 메뉴에서 직접 설치해 주세요.
